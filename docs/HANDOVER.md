### ٢.٣ الخطوط

ثلاثة خطوط، لكل منها دور محدد. التحميل عبر `next/font/google` في `app/layout.tsx`.

| الخط | متغير CSS | الاستخدام |
|------|-----------|-----------|
| **Cairo** | `--font-display` | H1، H2، H3، عناوين الأقسام، نص أزرار CTA. الأوزان: 400–800 |
| **IBM Plex Sans Arabic** | `--font-body` | نص الجسم، تسميات النماذج، التعليقات، إجابات FAQ. الأوزان: 300–600 |
| **IBM Plex Mono** | `--font-mono` | **الأرقام فقط**: kg، cm، أرقام الأسابيع، الأسعار، أرقام المراحل، الإحصاءات. لا يُستخدم مع النص العربي أبداً |

استخدام IBM Plex Mono للأرقام هو الإشارة الطباعية التي تحمل نبرة "القياس". كل رقم يقرؤه المستخدم يبدو دقيقاً وموثقاً.

#### طريقة الاستخدام في المكوّنات

```tsx
// رقم — IBM Plex Mono
<span className="text-mono-num">12</span>

// عنوان — Cairo
<h2 style={{ fontFamily: 'var(--font-display)' }}>...</h2>

// نص — IBM Plex Sans Arabic
<p style={{ fontFamily: 'var(--font-body)' }}>...</p>
```

الصنف `text-mono-num` معرّف في `app/globals.css` ويضبط `font-family` و`font-variant-numeric: tabular-nums`.

## ٤. القواعد الصارمة مع أسبابها

### ٤.١ قواعد البيئة

| القاعدة | السبب |
|---------|-------|
| استخدم `py` لتشغيل Python، لا `python` ولا `python3` | على هذا الجهاز، `python` و`python3` مداخل وهمية من متجر Windows |
| نظام التشغيل Windows، الشل PowerShell | المشروع يعمل محلياً على Windows |

### ٤.٢ قواعد اللغة

| القاعدة | السبب |
|---------|-------|
| `<html lang="ar" dir="rtl">` على العنصر الجذر | يُفعّل RTL تلقائياً لكل عناصر الصفحة |
| النص العربي فقط في الواجهة؛ الكود والتعليقات وأسماء الملفات بالإنجليزية | فصل واضح بين محتوى المستخدم ومحتوى المطوّر |
| لا `letter-spacing` على أي نص عربي | `letter-spacing` يكسر وصل حروف الكلمة العربية؛ تظهر الكلمة كحروف منفصلة |
| لا `text-transform` على أي نص عربي | الخط العربي لا يملك نظام حالة (uppercase/lowercase) |
| جميع نصوص الواجهة بالعامية الفلسطينية، لا بالفصحى | الجمهور في القدس؛ الفصحى تبدو كبروشور شركة لا كخطاب شخصي |
| العامية فلسطينية تحديداً، لا مصرية ولا خليجية | أمثلة: "ما زبطت" لا "مش شغلت"؛ "حدا" لا "أحد"؛ "هالمرة" لا "هذه المرة" |
| ممنوع كتابة نص يضمن نتيجة | لا أرقام خسارة وزن، لا نسب نجاح، لا وعود بنتائج محددة — سواء في placeholder أو نص حقيقي |

### ٤.٣ القواعد التقنية الصارمة

| القاعدة | السبب |
|---------|-------|
| لا ارتفاع ثابت `height`، ولا `max-height`، ولا `aspect-ratio` على البطاقات أو الشبكات | النص العربي في أحجام وأوزان معينة يكون أطول من نظيره اللاتيني؛ الارتفاع الثابت يقطع المحتوى |
| المساواة في الارتفاع فقط عبر `align-items: stretch` في CSS Grid | يضمن تمدد جميع الأعمدة لارتفاع أطولها دون قطع |
| لا `position: absolute` ولا margins سالبة لوضع نص أو سعر أو عنوان داخل بطاقة | في RTL، المواضع المطلقة تنكسر أو تتداخل مع نص آخر |
| لا `overflow: hidden` على أي عنصر أصل يحتوي نصاً | بعض الحروف العربية تنزل تحت خط الأساس؛ `overflow: hidden` يقطعها |
| Tailwind v4 يتجاهل القيم الاعتباطية التي تحتوي متغيرات CSS | مثال: `bg-[var(--color-primary)]` لا تعمل. استخدم CSS مباشرة لأي قيمة مرتبطة بمتغير |
| قدّم قبل أن تبني. لا تبني أي قسم قبل الموافقة عليه | |

## ٨. قواعد لا تظهر في CLAUDE.md

هذه قرارات اتُّخذت خلال الجلسات ولا توجد في الملف الرسمي:

- **لون واتساب معزول**: `#25D366` يُستخدم فقط على زر واتساب في القسم 11. ممنوع استخدامه كلون برند في أي مكان آخر.
- **الأرقام بالأرقام الغربية** (0–9) لا بالعربية-الهندية (٠–٩) في القياسات والإحصاءات — لأن الأرقام الغربية أسرع قراءةً في السياق القياسي.
- **شريط Demo**: يبقى طوال مراحل التطوير. يُزال فقط عند النشر الحقيقي.
- **next/font يستلزم literal strings**: خيارات دالة الخط في `layout.tsx` يجب أن تكون قيماً حرفية لا مراجع لمتغيرات — قيد في Next.js يمنع الاستيراد المباشر من `theme.ts` لهذه القيم. أسماء المتغيرات CSS يجب أن تطابق `fontConfig.*.variable` في `lib/theme.ts`.
